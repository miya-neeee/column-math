# ひっさんノート

小学生向けの、**ひき算とわり算の筆算**を練習するドリルです。

答えだけを入力させるのではなく、方眼のマス目に位置ごとに書き込む形にしています。「商を書く位置がずれる」「商の一の位の 0 を書き忘れる」といった、筆算そのもののつまずきを、答えの正誤とは別に検出できます。

**公開ページ:** https://miya-neeee.github.io/column-math/

---

## できること

- **ひき算** — 2けたか3けたか設定で選べます。くり下がりが必ず1回以上入ります。3けたでは `300 − 148` のように 0 をまたいでくり下がる問題も混ざります。
- **わり算** — 割られる数が2〜4けた、割る数は1〜2けた（1けたの場合2〜9）から設定で選べます。割る数が2けたのときは、割られる数は3〜4けたになります。商の一の位が 0 になり、あまりが出る問題が約3割混ざります。
- **とちゅうの式** — わり算では、割られる数の下のマスに筆算の途中経過を自分で書き込みます。答え合わせもここまで含めて行います。
- **答え合わせ** — マスごとに色分けします。書いたものは消えたり置き換わったりしません。
- **解説** — 間違えたときは、正しい筆算を別枠に表示し、1ステップずつ送りながら自分の答えと見比べられます。くり下がりの数字も出ます。
- **ヒント** — 詰まったときに「どこで止まっている？」から選ぶと、その場面の説明が出ます。答えそのものは出しません。
- 時間計測や連続正解数の表示はありません。最後に、間違えた問題だけをやり直せます。

### 操作

画面下のテンキーで入力します。物理キーボードでも、数字キー・Backspace・矢印キー・Enter が使えます。マスをタップすると入力位置を移せます。「けす」と Backspace は、今のマスが空なら直前に書いたマスを消します。

## データの取り扱い

**このアプリは、いかなるデータも送信も保存もしません。**

- ネットワーク通信を行いません
- ブラウザにも保存しません（localStorage・Cookie 等を使用していません）。成績はメモリ上だけに置かれ、ページを閉じると消えます
- 氏名・年齢・成績履歴といった項目そのものを持ちません
- アクセス解析・広告・外部フォントを含みません
- **外部ライブラリを一切使っていません。** 依存パッケージがないため、SBOM に載せる部品もありません

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体。CSP の指定もここ |
| `style.css` | 見た目 |
| `app.js` | 問題生成・筆算の手順計算・採点・画面 |
| `apple-touch-icon.png` | ホーム画面に追加したときのアイコン（180×180） |

ビルドはありません。**編集したファイルがそのまま公開されます。**

### Content-Security-Policy

`index.html` の `<meta>` で次の CSP を指定しています。

```
default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self' data:;
connect-src 'none'; base-uri 'none'; form-action 'none'
```

- スクリプトとスタイルは、このサイト自身の `app.js` と `style.css` だけが動きます
- 画像は、このサイト自身のファイル（ホーム画面用アイコン）と、`index.html` に埋め込んだファビコンだけです
- HTML に直接書いた `<script>`、`style="..."` 属性、`onclick="..."` 属性は、ブラウザが実行を拒否します
- `fetch` などによる通信や、外部の画像・スクリプト・スタイルの読み込みは、万一コードに紛れ込んでもブラウザが遮断します
- ただし、ページ自体を別のサイトへ移動させる操作（`location.href` の書き換えなど）は CSP では止められません。このアプリは送る対象のデータを持たないため、実害はありません

実際のブラウザ（Chromium）で、攻撃コードを仕込んだページを使って、インラインスクリプト・外部画像・style 属性・外部通信がすべて遮断されることを確認しています。

**制約:** 他サイトへの埋め込み（iframe）を禁止する `frame-ancestors` は、`<meta>` では指定できません。GitHub Pages はレスポンスヘッダも設定できないため、この対策は取れていません。ログインや重要な操作がないアプリなので、埋め込まれても実害はありません。

## スマホ・タブレットで使う

公開ページを開いて、ホーム画面に追加すると、アプリのように使えます。

- **iPhone・iPad（Safari）** — 共有ボタン →「ホーム画面に追加」
- **Android（Chrome）** — 右上のメニュー →「ホーム画面に追加」

スクリーンタイムの「許可されたWebサイトのみ」を使っている端末では、公開ページの URL を許可リストに追加してください。

古い端末でも動くように、新しい構文（`??` や `?.` など）は使っていません。iOS 12 前後でも動く見込みですが、実機では確認していません。iOS 14.5 未満では、一部の余白が詰まって表示されます。

## 編集するとき

- 動作確認は、`index.html` をブラウザで開くだけでできます（Edge・Chrome で確認済み）
- CSP の都合で、**HTML に `style="..."` や `<script>...</script>` を直接書くと動きません**。見た目は `style.css` にクラスを足して指定し、処理は `app.js` に書いてください
- 画面の要素は `app.js` の `h()` 関数で作っています。文字はテキストとして入るので、HTML として解釈されることはありません
- Claude Code で編集する場合のルールは `CLAUDE.md` にまとめてあります。Claude Code は起動時にこのファイルを読みます

## 公開

GitHub Pages の設定は次のとおりです。

- Settings → Pages → Source: **Deploy from a branch**
- Branch: `main` / `/(root)`

`main` に push すると、数分で公開ページに反映されます。

ルートにある空の `.nojekyll` は、GitHub Pages が既定で行う Jekyll の処理を止めるためのファイルです。これがあると、リポジトリの中身が加工されずにそのまま配信されます。
